# Agent Context

Before changing project direction, run/evaluation workflow, Director prompting, or autonomous execution behavior, read:

- `research/autonomous-operating-model.md`

Key operating reminders:

- Action budget exhaustion is an inspection checkpoint, not a failure by itself.
- Human review should improve confidence but should not block progress; use provisional work, queued review, generated states, or adjacent pivots.
- Preserve LLM Director agency. Guardrails should make the game safe and legible, not replace strategy with scripts.
- Skills should expose semantic Pokemon intentions and hide only low-level control mechanics.
